Administrador de Gastos

Aplicación web desarrollada con React y TypeScript para registrar y administrar gastos personales.

- Tecnologías
React
TypeScript
CSS

Funcionalidades
- Registrar gastos
- Mostrar listado de gastos
- Eliminar gastos
- Editar gastos
- Filtrar gastos por categoría
- Validación de formularios
- Manejo de estado con React Hooks
